# Telegram AI Personal Expense Tracker

A simple personal expense tracking automation using:

- Telegram Bot
- Make.com
- Google Gemini AI
- Google Sheets

The user sends a simple expense message in Telegram, Gemini understands the amount and category, and Make.com automatically stores the transaction in Google Sheets.

No custom backend, VPS, Docker, or database is required.

---

## Project Flow

```text
Telegram Bot
      ↓
Google Gemini AI
      ↓
Google Sheets
```

Example Telegram message:

```text
tea 200
```

Gemini converts it into:

```json
{
  "amount": 200,
  "type": "Expense",
  "category": "Food",
  "description": "Tea",
  "payment_mode": ""
}
```

Then Make.com stores the transaction in Google Sheets.

---

# Features

- Telegram-based expense entry
- AI-based expense classification
- Automatic amount extraction
- Automatic category detection
- Expense, income, investment, and savings classification
- Google Sheets storage
- Timestamp tracking
- Category-wise expense tracking
- Pie chart for spending categories
- Daily spending chart
- No custom backend required
- Runs automatically in Make.com cloud

# Step 1 — Create Telegram Bot

Open Telegram.

Search for:

```text
@BotFather
```

Send:

```text
/newbot
```

BotFather will ask for a bot name.

Example:

```text
Personal Expense Tracker
```

Then create a username ending with `bot`.

Example:

```text
personal_expense_tracker_bot
```

BotFather will generate a Telegram Bot Token.

Keep this token private.

Do not upload it to GitHub.

---

# Step 2 — Create Make.com Scenario

Login to:

```text
https://www.make.com
```

Create a new scenario.

Add these modules:

```text
Telegram Bot
      ↓
Google Gemini AI
      ↓
Google Sheets
```

---

Add:

```text
Telegram Bot
```

Select:

```text

```

Save the connection.

```text

```

```text

```

# Make.com Blueprint Backup

The complete Make.com automation can be exported as a Blueprint.

Open the scenario.

Click:

```text
Edit
```

Inside the Scenario Builder, open the menu.

Select:

```text
Export Blueprint
```

Make.com downloads a JSON file.

Example:

```text
Integration Telegram Bot.blueprint.json
```

Keep this file as a backup.

---

# Import Blueprint

To restore the workflow later:

1. Create a new Make.com scenario
2. Open Scenario Builder
3. Select:

```text
Import Blueprint
```

4. Upload the Blueprint JSON file

After importing, reconnect:

- Telegram Bot connection
- Google Gemini AI connection
- Google Sheets connection

The Blueprint stores the scenario structure and mappings, but account credentials should be reconnected.
